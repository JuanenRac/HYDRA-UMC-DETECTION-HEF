## Reporting a Vulnerability

**CRITICAL: Do not report safety-critical vulnerabilities through public GitHub issues.**

In an AI-driven industrial system, a compromised model can lead to undetected failures or safety breaches. If you discover a vulnerability affecting the **HEF binary integrity**, **model poisoning**, or **compiler bypasses**:

1. **Email**: Send a detailed report to `electrohobby3d@gmail.com`.
2. **Impact**: Describe if the bug allows bypassing detection, crashing the NPU, or injecting malicious weights.
3. **Response**: Initial acknowledgment within 48 hours.

We follow a coordinated disclosure policy to ensure hardware safety before public release.
